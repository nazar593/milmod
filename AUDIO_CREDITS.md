# Источники звука MilMod 0.4.0

Двигатели собраны из полевых записей с открытой лицензией CC0. Записи отредактированы для игры. Для каждой модели выбраны собственный фрагмент, высота тона и фильтрация. Использованные записи подходят по классу двигателя. Они не являются записями всех перечисленных моделей.

| Тип | Исходная запись |
|---|---|
| Квадрокоптер | qubodup, Big Slow Heavy Drone Hovering Idle Loop. Основа — запись DJI Mavic Mini 2 пользователя Sadiquecat. [Freesound](https://freesound.org/people/qubodup/sounds/854382/) |
| Винтовой двигатель | Breviceps, Propeller plane. [Freesound](https://freesound.org/people/Breviceps/sounds/515293/) |
| Дизель | C-V, Diesel idle 1.wav. [Freesound](https://freesound.org/people/C-V/sounds/565598/) |
| Реактивный пролёт | unfa, Jet Flyby 1. [Freesound](https://freesound.org/people/unfa/sounds/168079/) |

Звуки рамп, подвеса, сброса, повреждения и панели синтезированы для этого выпуска. В аудиособытиях MilMod нет ссылок на аудиофайлы Minecraft. Формат ресурсов — Ogg Vorbis, моно.

Звуковой эффект игрового взрыва также синтезирован. Его генератор находится в `tools/impact_sound.py`.
