# MilMod 0.9.2 · доводка клиентских эффектов

Minecraft Java 1.20.1, Forge 47.4.28, Java 17.

## Изменения

| Тема | Изменение | Код |
|---|---|---|
| Отскок искр | Искры проверяют коллизию по формам блоков, отражают скорость и могут трижды отскочить от пола. Ванильная остановка частицы на контакте больше не блокирует отскок | `client/HeavyParticles.java` |
| Очередь звука | При приходе волны дальность проверяется заново. Посторонние препятствия приглушают звук. Конец луча вынесен из поверхности попадания. Смерть, смена мира и смена игрока очищают очередь и петли | `client/HeavyExplosionClient.java` |
| OpenAL | Поток игровых событий помечает исключённые каналы. Вызовы фильтра выполняются в обновлении канала. Петли контузии восстанавливаются после звукового сброса с ограниченной частотой. При отсутствии EFX причина выводится в debug-лог один раз | `client/ConcussionAudio.java`, `client/mixin/ChannelFilterMixin.java` |
| Экран | Тряска от нескольких взрывов ограничена по осям. Слабая вспышка не обрывает более яркую. Цепочка размытия удаляется при окончании эффекта, смерти, смене мира и перезагрузке ресурсов | `client/HeavyExplosionClient.java`, `client/ConcussionBlur.java`, `client/ClientEvents.java` |

## Настройки

Файл `config/milmod-client.toml`, секция `[effects]`. Значения по умолчанию сохраняют эффекты включёнными.

| Параметр | Значение по умолчанию | Действие |
|---|---:|---|
| `screenFlashStrength` | `1.0` | Яркость экранного слоя, диапазон 0–1 |
| `concussionBlur` | `true` | Размытие при контузии |
| `concussionAudio` | `true` | Приглушение EFX, звон и пульс |
| `cameraShake` | `true` | Тряска камеры |
| `blastLight` | `true` | Клиентская подсветка граней |

Настройка серверного временного светового блока находится отдельно в `milmod-server.toml` (`temporaryLight`).

## Проверка

Сборка Java выполнена JDK 17 против официально отображённых имён Forge 47.4.28. JAR ремаппирован Forge Auto Renaming Tool. Проверка сервера охватывает штатную детонацию, воронку, обломки, отключение разрушения блоков, погасание света, загрузку NBT и запуск техники. Сетевой протокол прежний.
